# Installation

Starting with version 1.2.1, OmniMirror is distributed as a Blender extension. It requires Blender 4.4 or newer.

## Upgrade from 1.2.0 or earlier

If you already have the legacy version installed, open **Edit > Preferences > Add-ons**, find OmniMirror, and disable it before installing the extension.

## Install the extension

1. Download the OmniMirror ZIP and keep it zipped.
2. In Blender, open **Edit > Preferences > Get Extensions**.
3. Open the menu in the upper-right corner and choose **Install from Disk**.
4. Select the ZIP and confirm the installation.
5. If OmniMirror is disabled after installation, enable it under **Preferences > Add-ons**.

Open the sidebar with **N** in the 3D Viewport or UV Editor and select the **OmniMirror** tab.

[Blender Manual on installing extensions](https://docs.blender.org/manual/en/5.4/editors/preferences/extensions.html#installing-extensions)
